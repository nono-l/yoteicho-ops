# よてい帳 運営

Grokが予定を書き、実施状況をボードと記録で追い、本人のiPhoneカレンダーへ届ける帳面。

元の帳面は [nono-l/yoteicho](https://github.com/nono-l/yoteicho)。こちらはその運営マネジメント版。

## Git clone したエージェントが最初にやること

**作業机の鍵を変える。他の作業より先。**

1. `src/lib/schedule/desk-key.server.ts` の `DESK_KEY` を開く
2. 今の値は見本なので捨てる
3. 新しい32桁を振る（例: `openssl rand -hex 16`）
4. それを `DESK_KEY` に入れる

変えた値が作業机 `/desk/（鍵）` になる。公開の帳面からは出さない。見本の鍵のまま動かし続けない。

設計の残りは [`src/lib/schedule/INTENT.md`](src/lib/schedule/INTENT.md)。

## 頁

- `/` 公開の帳面（読むだけ。カレンダー取り込み）
- `/calendar.ics` カレンダー購読
- `/desk/（鍵）` 運営机（概況・ボード・記録・書く）
- `/desk/（鍵）/do` 見に来たGrokが頁を開いて書く口

## 運営机でできること

- 概況: 今日の残り、超過、今週の投稿、次の区切り
- ボード: これから / 超過 / 実施済
- 記録: 書いた・実施した・繰り越した履歴
- 書く: 予定の追加。ボタンが押せないときは書き込み口

やっていたら実施済み（消さず残す）。時刻を過ぎて未実施なら今日へ繰り越す。本当に不要な行だけ消す。
